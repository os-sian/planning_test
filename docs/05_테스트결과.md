# EPIC별 구현·검사·사용자 확인 결과

작성일: 2026-10-12  
현재 대상: **EPIC별 기존 확인 기록 유지 / EPIC 3 구현·검사 및 사용자 확인(6절)**
상태: EPIC 1 로컬 구현·자동 검사·사용자 직접 확인 완료. 운영 연결·코드 보관·배포는 미완료.

## 1. 범위와 환경

- 대상 Story는 1.1 본인 접속, 1.2 기존 판매 조회, 1.3 신규 판매 등록, 1.4 기존 판매 정정이다.
- EPIC 2·3의 업무 화면과 API는 이번에 구현하지 않았다. 판매 변경을 검증하는 데 필요한 재고·운영비 계산 기반은 포함했다.
- Supabase 프로젝트가 없다는 사용자 답변을 받았고, 사용자가 **로컬 검사 환경으로 먼저 테스트하기**를 승인했다.
- 로컬 검사는 Next.js 16.4.0·Node.js 24·실제 PostgreSQL 엔진인 PGlite와 비밀번호 로그인을 사용한다. 기록은 `.local/database`에 보존된다. 가짜 저장·브라우저 저장소·완료 문구만 바꾸는 동작은 사용하지 않았다.
- 본인 계정 정보는 `.local/로그인정보.txt`, 인증 정보는 비밀번호 해시와 서버 세션으로 관리한다. 이 파일과 DB·환경 설정은 코드 보관 대상에서 제외한다.
- 테스트 주소: `http://127.0.0.1:3000/login`. 서버는 이 컴퓨터에서만 접근하도록 실행했다. 모바일 자동 검사는 Chromium의 390×844 화면 크기로 수행했으며 실제 휴대폰 접속 검사는 아니다.
- 운영용 Supabase 인증·클라우드 DB·GitHub 업로드·Vercel 배포는 미연결·미검사다. 운영용 연결 코드와 준비 절차는 `README.md`에 있다.
- 제공 가상 JSON을 최초 한 번 반영했다. 원본 JSON·엑셀을 수정하지 않는다. 브라우저 자동 검사의 2026-09-21~25 임시 판매는 검사 후 삭제했다.

검사 중 발견한 문제와 수정:

- 모바일 검사에서 오류 안내와 Next.js 화면 이동 안내를 같은 대상으로 찾던 검사 조건을 수정했다. 이후 모바일 검사 통과.
- 초기 JSON 읽기가 배포 코드에 함께 묶이면서 엑셀 임시 파일 경로를 추적하던 빌드 오류를 수정했다. 초기 자료 읽기를 초기화용 코드로 분리하고 로컬 자료·비밀 파일을 배포 추적에서 제외했다. 이후 빌드 통과.
- 필터·등록 날짜 변경 후 이전 목록이 다시 덮일 수 있는 흐름, 로그인 재확인 뒤 오류 안내, 큰 금액 표시의 숫자 정밀도를 보완했다.
- 저장 연결 실패 안내를 쉬운 한국어로 통일하고, 입력 보존·재시도와 자격 소멸 후 본인 재확인을 실제 브라우저에서 검사했다.

## 6. EPIC 3 구현·검사와 직접 확인 (2026-10-12)

현재 대상은 **EPIC 3. 재고 관리와 전체 복구**다. 기존 EPIC 1·2 확인 기록은 유지한다. 이번 요청으로 EPIC 3만 추가 구현했으며, 기존 판매·비용·보고서·백업 기반을 연결해 검사한다. **사용자 직접 확인 전이므로 EPIC 3은 미완료**다.

- `/inventory`: 기준일 잔량·소진·음수·계산 불가, 최근 실측, 원기록 증감과 재계산 실측 차이, 입고·폐기·실측 신규 등록. 재고 수정·삭제는 추가하지 않았다.
- `/restore`: JSON 검증 → 현재/백업 기록 개수·기간 비교 → 전체 교체 확인 → 트랜잭션 복원. 선택·취소는 원기록을 바꾸지 않는다.
- 공급사·입고 기준 단위원가는 선택 사항. 구매대금·폐기비는 비용에 자동 추가하지 않고 가격 이력을 유지한다.
- 실측은 당일 마지막 수량으로 한 번 반영한다. 과거 판매 정정은 실측수량을 유지하고 계산 차이만 바꾼다.
- 복원 확인은 10분 유효하며 자료 버전과 연결된다. 비교 후 변경·복원 이후 오래된 저장은 거부한다. 전체 교체 도중 오류는 기존 자료·세대를 유지한다.
- 로컬 서버는 `http://127.0.0.1:3000`이다. 브라우저 자동 검사는 별도 `/tmp/prep-epic3-browser-db`와 3001 포트를 사용한다. 사용자 DB의 판매·비용·재고를 자동 검사로 변경하지 않는다.
- 현재 로컬 파일 전송 지원은 20MB·전체 100,000행 이하다. 50MB 대용량 검증과 운영 Supabase 비공개 Storage/TUS 업로드, 실제 다른 기기·휴대폰, GitHub·Vercel 배포는 미완료다. 운영 복원 API는 Storage 연결 전 차단한다.
